## Selected work

**[Tether](https://github.com/distru3/tether)** · personal project · 2026<br>
Private-by-default screen-time tracker and limiter for Windows. It tracks app usage locally, categorizes activity, and enforces daily limits by freezing processes instead of killing them, so unsaved work survives.<br>
`Rust` `Tauri 2` `React` `SQLite` `Windows APIs` — [latest release](https://github.com/distru3/tether/releases)

**[Astroos — Derna Seen by Radar](https://astroos-curiou-sar-1iat.vercel.app/)** · team project · 2025<br>
A data-storytelling platform that reveals the 2023 Derna flood through Synthetic Aperture Radar: Sentinel-1 flood mapping, radar-vs-optical comparison, interactive quizzes, and an AI chatbot grounded in NASA's open data.<br>
`SAR / Sentinel-1` `NASA Open Data` `React` `Vercel` — [team page](https://www.spaceappschallenge.org/2025/find-a-team/astroos1/)

Arabic (RTL) content platform with role-based publishing for readers, writers, and admins, weekly scheduling with Hijri dates, categorized posts, reactions, and threaded comments.<br>
`TypeScript` `React 18` `Node.js / Express` `Prisma` `PostgreSQL`

`React 19` `FastAPI` `PyTorch / Transformers` `BookNLP`

Also: [Hogwarts for Programming](https://github.com/mohamedadel96e/Hogwarts-for-programming) (PHP 8 · MySQL · MVC) and [Eco-Quest](https://github.com/distru3/Eco-Quest_NASA), a Godot game about pollution built for NASA Space Apps Cairo 2024.
